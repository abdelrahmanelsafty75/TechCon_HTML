# TechCon 2024 Website

A multi-page static conference website built with semantic HTML5 to demonstrate core web structure and accessibility.

## 📂 File Structure

The website is located in the `techcon_website` folder:

- **index.html**: Homepage with global navigation and embedded video.
- **about.html**: Conference details using semantic `<article>` tags.
- **schedule.html**: Event timetable using an accessible `<table>`.
- **register.html**: Sign-up form with input validation.
- **contact.html**: Contact form, social links, and embedded Google Map.
